# 劳动关系知识库 · 浏览器版

在 GitHub Pages 上直接运行，可导入并阅读 PDF、按专题归档、做批注、查原文证据，并整理文献关系。导入的资料保存在当前浏览器。使用「备份与迁移」在不同设备或浏览器间转移资料。

PDF 的提取和证据检索在浏览器内执行。双语发现会向公开来源提交检索词。部分来源的浏览器跨站接口可能不可用，可以用网页提供的站外入口。

## 使用

打开 [劳动关系知识库](https://lhongwei974-source.github.io/labor-relations-library-web/)。选择「导入 PDF」即可开始，网页中的初始资料和批注练习 PDF 均为示例。

## 研究设计对照

导入 PDF 后，可在「核对并归档」看到研究设计候选。从文章详情也能打开「研究设计」，填写 X、Y、各自的指标口径、回归模型和数据来源。每条自动候选附有 PDF 页码，可打开原页核对。缺失字段可以手填。若同一篇文章有基准回归和其他检验，可分别添加一组，并逐组标记已核对。

从侧栏打开「研究设计对照」，按题名、变量、指标、模型、数据或核对状态筛选，再导出当前结果为 Excel 可打开的 CSV。研究设计随知识库备份转移。
